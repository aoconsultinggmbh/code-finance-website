Häufige Fragen

Fragen, die vor dem ersten Termin aufkommen

Was kostet ein Erstgespräch bei CODE FINANCE?

Das Erstgespräch bei der CODE FINANCE GmbH ist unverbindlich. Es dient dazu, die Ausgangslage zu klären und zu prüfen, ob eine Zusammenarbeit sinnvoll ist. Vergütet wird die Arbeit eines Versicherungsmaklers üblicherweise über die Courtage des Produktanbieters, bei Beratungen gegen Honorar wird die Vergütung vorher schriftlich vereinbart.

Ist CODE FINANCE an eine Versicherungsgesellschaft gebunden?

Nein. Die CODE FINANCE GmbH arbeitet als Versicherungsmakler mit Erlaubnis nach § 34d Abs. 1 GewO und ist an keine Gesellschaft gebunden. Die Auswahl richtet sich nach der Situation des Kunden, nicht nach dem Sortiment eines einzelnen Anbieters.

Wo finde ich CODE FINANCE in Karlsruhe?

Die CODE FINANCE GmbH hat ihren Sitz in der Tullastraße 58, 76131 Karlsruhe. Sie erreichen das Büro telefonisch unter +49 721 95279527 und per E-Mail an frederik.demski@codefinance.de. Termine finden im Büro in Karlsruhe oder per Video statt.

Wie schnell bekomme ich eine Rückmeldung auf meine Anfrage?

Die CODE FINANCE GmbH meldet sich innerhalb von 24 Stunden auf eingehende Anfragen. Für jedes Mandat gibt es einen festen Ansprechpartner, sodass Rückfragen nicht jedes Mal neu erklärt werden müssen.

Was bedeutet Beratung aus einer Hand?

Absicherung, Finanzierung und Vermögensaufbau werden bei der CODE FINANCE GmbH gemeinsam betrachtet statt einzeln verkauft. So lassen sich Doppelstrukturen erkennen, Beiträge sinnvoll verteilen und spätere Schritte wie eine Immobilienfinanzierung von Anfang an mitdenken.

Berät CODE FINANCE auch Selbstständige und Unternehmen?

Ja. Die CODE FINANCE GmbH betreut Selbstständige, Betriebe und Unternehmen bei betrieblicher Absicherung, bei der Struktur der Verträge und bei finanziellen Lösungen für den geschäftlichen Alltag. Private und betriebliche Themen werden dabei zusammen betrachtet.

Kann ich bestehende Verträge prüfen lassen, ohne sie zu wechseln?

Ja. Eine Bestandsaufnahme ist ergebnisoffen. Verträge, die passen, bleiben bestehen. Ein Wechsel wird nur vorgeschlagen, wenn er einen erkennbaren Vorteil bringt, und die Gründe dafür werden schriftlich festgehalten.

Findet die Beratung persönlich oder digital statt?

Beides ist möglich. Termine finden im Büro in Karlsruhe, beim Kunden oder per Videogespräch statt. Unterlagen lassen sich digital austauschen, Unterschriften sind je nach Produkt auch elektronisch möglich.
